 Este programa implementa un reloj digital que muestra la hora en formato de texto catalán.
 Utiliza un bucle 'while' infinito para actualizar la hora y 'if/else' para redondear los minutos.
 Emplea un array de strings para los nombres de las horas y un 'switch' para definir los "quarts".
 Calcula la lógica horaria ajustando el formato de 12h y determinando la hora siguiente.
 Sirve para practicar arrays, lógica matemática y estructuras de control de flujo continuo.
