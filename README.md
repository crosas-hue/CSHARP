# CSHARP
A lo largo de estas cuatro prácticas, he realizado un viaje completo por los fundamentos de la creación de software con C#.
Comencé desde la base, aprendiendo a guardar información y a comunicarme con el usuario para pedir datos y mostrar resultados.
Poco a poco, doté de "inteligencia" a mis programas, enseñándoles a tomar decisiones automáticas mediante menús y condiciones lógicas.
Para ser más eficiente, incorporé herramientas que automatizan tareas repetitivas, evitando escribir el mismo código una y otra vez.
También aprendí a gestionar grandes volúmenes de datos usando listas y a manipular texto para crear experiencias más humanas.
Finalmente, organicé todo este caos dividiendo los problemas grandes en pequeñas funciones reutilizables y ordenadas.
Desde una calculadora básica hasta un ingenioso reloj en catalán, estos ejercicios demuestran mi capacidad para convertir problemas reales en soluciones digitales funcionales.
