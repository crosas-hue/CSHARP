
 Este programa muestra un menú para que el usuario elija entre dos operaciones matemáticas.
 Utiliza la estructura 'switch' para decidir si realizar una suma o calcular un área.
 En el primer caso, suma un número entero y uno decimal convirtiendo los datos de entrada.
 En el segundo caso, pide el largo y el ancho para calcular el área total de un rectángulo.
 Sirve para practicar la declaración de variables y la conversión de tipos con 'Convert'.
