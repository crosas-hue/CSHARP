 Este programa agrupa cuatro ejercicios controlados por un menú 'switch'.
 Usa arrays y listas para gestionar números aleatorios, hallando máximos, mínimos y medias.
 Analiza cadenas de texto contando vocales y simula un cajero usando funciones para el saldo.
 Aplica bucles 'for' y 'foreach', condicionales y métodos con retorno para organizar el código.
 Sirve para practicar colecciones, manipulación de strings y modularización.
